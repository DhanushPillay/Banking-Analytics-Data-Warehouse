# Synopsis: Customer Behavioral Analysis and Loan Default Classification

Loan defaults cost banks directly, and spotting risky borrowers before granting a loan reduces those losses. This project predicts loan default risk from customer transaction behavior using the PKDD'99 Financial Dataset, real anonymized records of a Czech bank (1993 to 1998) with 682 loans and about one million transactions.

For each loan, 13 behavioral features were built strictly from transactions dated before the loan grant date (counts, totals, balances, activity rate), joined with loan terms and demographics into `data/loan_features.csv` (682 rows). The target is binary: 606 good loans versus 76 defaults (11.14 percent).

Six scikit-learn classifiers (Decision Tree, Naive Bayes, Random Forest, SVM, KNN, Gradient Boosting) were each trained twice on a stratified 75/25 split: once on raw imbalanced data and once with SMOTE-balanced training data. Each was then tuned with a randomized hyperparameter search and scored under repeated stratified cross-validation (5 folds x 10 repeats, 50 estimates per configuration). The selected model is tuned Gradient Boosting on the unresampled data, at F1 0.571 ± 0.120, Average Precision 0.654, and ROC-AUC 0.864; tuned Random Forest ties it on F1 and leads on both Average Precision (0.661) and ROC-AUC (0.877). SMOTE lowered F1 for five of the six models and helped only KNN, so the recommended default is the unresampled baseline. Low pre-loan balances (`min_balance`, `balance_at_loan`) are the strongest default signals; age and gender carry none.

The bank should add balance-level checks to loan review, weight loan amount against demonstrated balance capacity (the worst quadrant of pre-loan balance crossed with loan amount defaults at 23.3 percent against a portfolio base rate of 11.1 percent), and revalidate on recent portfolio data before deployment, since only 76 defaults support these estimates. Full details are in `Jury2_Report.md`; all results regenerate by running `notebooks/01` to `05` in order.
